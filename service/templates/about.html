How it works

Pipeline

  1. Calibration. Each phone films a checkerboard. OpenCV 5 finds the corners (findChessboardCorners, cornerSubPix) and solves the camera pose (solvePnPGeneric, IPPE).
  2. 2D pose. A person detector (YOLOX), a whole-body pose network (RTMW-x, 133 keypoints) and a hand network (RTMPose) run through the OpenCV 5 DNN engine (cv2.dnn).
  3. Synchronization. The phones are not started together. The frame offset of every camera is found from the motion itself: epipolar consistency and multi-view reprojection on frames where both cameras see the person.
  4. Triangulation and smoothing. Views are fused with per-camera soft trust, then a bidirectional Kalman/RTS smoother removes jitter while keeping fast motion fast.
  5. Export. The 3D skeleton is written as BVH for animation tools and game engines.

Cloud deployment

One script provisions the AWS stack.

Amazon CloudFront
HTTPS endpoint; the instance accepts traffic only from CloudFront.
Amazon EC2
m7i-flex.large (2 vCPU) runs this service and the pipeline on CPU.
Amazon S3
Code bundle, model weights, trials, precomputed results and run outputs.
AWS Systems Manager
Password in Parameter Store (SecureString); administration through Run Command, no SSH.
Amazon CloudWatch
Service and web-server logs; run and per-stage timing metrics.
AWS IAM
Instance role limited to the deployment bucket, one parameter path, one log group and one metric namespace.

Data

The trials come from the OpenCap LabValidation dataset (Uhlrich et al., "OpenCap: Human movement dynamics from smartphone videos", PLOS Computational Biology, 2023), released under Apache-2.0. Its participants consented to public sharing of their videos. Ground truth is the marker-based motion capture recorded in the same session.

Responsible use

  • This deployment shows only consented, publicly released videos and accepts no uploads.
  • The system estimates skeleton keypoints. It does not identify people.
  • Access is password protected and served over HTTPS. Live run outputs are deleted after 7 days.
