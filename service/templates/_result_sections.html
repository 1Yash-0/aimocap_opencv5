How much the skeleton shakes compared with the real motion (mm per frame squared). Lower is smoother.

Use the motion in your project

  1. Download {% if "motion.bvh" in downloads %}motion.bvh{% else %}motion.bvh{% endif %}, the motion in BVH format.
  2. In Blender, choose File > Import > Motion Capture (.bvh). If the motion is the wrong size for your character, adjust the scale in the import options.
  3. Retarget the motion onto your character in Blender, or with the Unreal Engine IK Retargeter.
  4. In Unity, export an FBX from Blender and import it with its rig set to Humanoid.
